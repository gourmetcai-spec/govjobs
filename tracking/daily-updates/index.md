# Daily job discovery updates

Each Step 1 run adds a dated report listing newly found jobs, application deadlines, confirmed unmet requirements, requirements needing verification, current resume PDFs and next actions. Multiple updates on the same date have separate run IDs.

Reports are historical snapshots. A job recheck or resume revision is an update to an existing job, not a new discovery. Configuration-only updates do not create discovery reports.

| Run date / ID | New jobs | Existing-job changes | Outcome / report |
|---|---:|---:|---|

New reports will be appended here during subsequent Step 1 runs. Earlier run evidence remains under `tracking/runs/` and in `joblog.md`.
