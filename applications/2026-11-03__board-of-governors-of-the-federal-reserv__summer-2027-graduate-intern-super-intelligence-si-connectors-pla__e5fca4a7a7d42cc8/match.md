Summary
The Federal Reserve Board (Board) provides students opportunities for career success. The Board’s Internship program is designed to provide valuable work experience for undergraduate and graduate students considering careers including, but not limited to, economics, finance and accounting, information systems, and data analysis. The Board believes that by combining academic endeavors with project-related work experience, qualified and capable college students can gain the practical knowledge need in a competitive global job market. Internships are paid positions with salaries commensurate with credit hours; internships may be in-person, remote or hybrid, depending on the needs of the team. Employment in the Board’s internship program is granted to U.S. citizens. Applicants must be currently enrolled in an undergraduate or graduate degree program at an accredited university and returning to continue studies after the internship. Interns receive a syllabus or research project plan outlining their projects and goals for the internship. Interns are assigned a supervisor or mentor to guide them through their internship, and regular check-in meetings with their manager to manage performance expectations and assist with learning goals. Interns have access to a wide range of training programs and events for professional development purposes.
As a Super Intelligence (SI/AI) Connectors Platform intern, you will work in the Application Infrastructure Support (AIS) unit of the Division of Information Technology, on the team building the Board's governed platform for connecting SI/AI tools to enterprise data and systems. The team designs, hosts, and operates Model Context Protocol (MCP) servers, retrieval-augmented generation (RAG) services, and the identity, gateway, and inventory layer that lets SI/AI applications and agents reach Board data securely. The platform runs on Kubernetes (Amazon EKS) in the Board's AWS environment and is built and delivered entirely through infrastructure as code and CI/CD pipelines. You will work alongside the Board's SI/AI Program and with the data scientists, economists, and analysts who use these connectors.
What You'll Be Doing
SI/AI Connectors Platform interns support the team in
·         Building and deploying MCP servers that expose Board data sources and tools to SI/AI clients such as Claude Code and Claude Desktop, using Python and the MCP SDK
·         Standing up and testing RAG components: document ingestion, chunking, embeddings, and vector search on PostgreSQL with pgvector
·         Delivering platform changes the way the team does: Terraform for cloud infrastructure, Ansible for configuration, GitLab CI pipelines for build and test, and ArgoCD GitOps for deployment to Kubernetes
·         Contributing to the identity and access layer for SI/AI connectors, including OAuth client registration, audience-bound tokens, and routing through the LiteLLM gateway
·         Populating and maintaining the MCP connector inventory and catalog so Board staff can discover what connectors exist, who owns them, and how to connect
·         Writing the templates, documentation, and quick-start guides that let other Board teams build connectors to enterprise standards
·         Participating in daily stand-ups, sprint planning, and design reviews with engineers, architects, and the SI/AI Program
Learning Objectives
Over the course of the internship, the intern will:
·         Build, containerize, and deploy a working MCP server for a Board data source, with authentication and gateway registration, from a starter template to a running endpoint on the platform
·         Implement a RAG ingestion and retrieval pipeline on PostgreSQL with pgvector and measure its retrieval quality against a defined test set
·         Write and run a GitLab CI pipeline that builds a container image, executes automated tests, and deploys to the Kubernetes platform through ArgoCD
·         Author Terraform and Ansible changes to the platform's infrastructure and configuration, delivered through merge requests and code review
·         Apply the platform's security controls (OAuth 2.0 audience-bound tokens, deny-by-default authorization, secrets management, audit logging) to the connector they build
·         Produce a developer quick-start guide and present the completed work to the AIS team and SI/AI Program
While completing these learning objectives, the intern will gain hands-on experience with Python, Kubernetes, AWS, Terraform, Ansible, GitLab CI, ArgoCD, PostgreSQL with pgvector, and the Model Context Protocol; gain a working understanding of how a regulated institution governs SI/AI access to enterprise data; and help determine whether a career in SI/AI platform or infrastructure engineering is of interest upon graduation.
Previous Intern Projects
Previous interns on the SI/AI Program and connectors work had the opportunity to contribute to projects such as
·         Drafting the product canvas for the Board's governed RAG platform
·         Prototyping MCP servers for economic data sources, including FRED and Haver
·         Evaluating hosting options and documenting architecture decisions
·         Standing up a PostgreSQL and pgvector replica of a Board data repository for retrieval use cases
·         Testing SI/AI connector authentication paths end to end with Claude Code
·         Building GitLab CI and Ansible automation for server provisioning and patching
Through these projects, you will work with infrastructure engineers, database administrators, cloud architects, and data scientists across the Board.
