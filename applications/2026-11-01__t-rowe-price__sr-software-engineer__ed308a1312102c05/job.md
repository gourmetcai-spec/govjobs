Role Summary
T. Rowe Price Associates, Inc. seeks a Senior Software Engineer to:
Create and maintain complex technical solutions and a suite of next-generation, cloud native applications.
Plan and implement large-scale, enterprise-level distributed applications.
Support complex data infrastructure, and present user-friendly reports.
Contribute to all phases of the project lifecycle, including requirements gathering, planning, solution design, and application.

Qualifications
Required:
Master’s degree in Computer Science, or a related technical field, PLUS
Two (2) years of experience in software development;
Object-oriented programming in Java backend for mobile applications, RESTful Webservices, Spring, distributed code repository (Git or Mercurial), and automated CI/CD pipelines (Jenkins or Gitlab CI);
Apigee, Splunk, and IAM;
Amazon Web Services cloud computing services, including S3, ECS, EC2, SQS, Elasticache, ELB, Fargate, CloudWatch, CloudFront, and Lambda.

FINRA Requirements
FINRA licenses are not required and will not be supported for this role.

Work Flexibility
This role is eligible for hybrid work, with up to three days per week from home.
